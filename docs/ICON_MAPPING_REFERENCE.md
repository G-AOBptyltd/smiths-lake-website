## 📝 Tips for Content Creators

### ✅ To Get the Right Icon Automatically:

1. **Use descriptive titles** with specific keywords
2. **Include the activity/service type** in the title
3. **Set the correct category** in Notion
4. **Be consistent** with naming conventions

### ✅ Examples of Good Titles:

- "Coastal Walking Group" → 🥾
- "Community Art Workshop" → 🎨
- "Beach Clean-Up Program" → 🏖️
- "Bird Watching Group" → 🦜
- "Recycling Drop-Off Centre" → ♻️

### ❌ Avoid Vague Titles:

- "Community Event" → Generic icon
- "Group Meeting" → Generic icon
- "Local Service" → Generic icon
