# 🎨 Icon System Management Guide

**For PPCA Committee Members & Content Editors**

---

## 📖 What This Guide Is For

This guide explains how the website's **automatic icon system** works and how you can influence which icons appear for your content without needing to write code.

---

## ✨ How Icons Are Chosen Automatically

When you add new content to Notion, the website **automatically picks the best icon** using this logic:

### **Priority System:**

1. **📌 Exact Title Match** (Highest Priority)
   - If your title exactly matches a known item, it gets that specific icon
   - Example: "Fire Station (RFS) Existing" → 🚒

2. **🔍 Keyword Search**
   - If the title contains certain keywords, it gets a related icon
   - Example: Title includes "boat" → 🚤

3. **🏷️ Category Match**
   - If no title match, the system uses your Category field
   - Example: Category is "Bushfire" → 🔥

4. **📂 Section Default**
   - If nothing else matches, uses the section's default icon
   - Example: Emergency & Safety section → 🚨

## 🆘 What If I Want a Different Icon?

### **Option 1: Change Your Title**
Adjust the wording to include keywords that trigger the icon you want.

**Example:**
- Current: "Community Gardening" → 🤝 (generic)
- Better: "Garden Club" → 🌻 (specific)

### **Option 2: Request a New Mapping**
Contact your technical administrator (Rob or Agility G) and request:

**"Please add this exact title to the icon system:**
- Title: [Your exact title]
- Desired Icon: [The emoji you want]"

They can add it to the system in 2 minutes.

## ❓ Common Questions

### **Q: Can I choose any emoji I want?**
**A:** Not directly through Notion, but you can request new mappings. The technical team can add any emoji to the system.

### **Q: What if my new content gets the wrong icon?**
**A:** First, check if adjusting your title with keywords helps. If not, request a custom mapping from the technical team.

### **Q: Why does the system use emojis instead of images?**
**A:** Emojis are:
- Universally supported across all devices
- Accessible to screen readers
- Lightweight (no image files to manage)
- Consistent across the site

### **Q: Can I see all available icons?**
**A:** Yes! This document lists all 100+ icons. The system can match hundreds of variations automatically.

### **Q: What happens if I create something completely new?**
**A:** The system will use the section's default icon (e.g., 🚨 for Emergency, 👥 for Groups). You can then request a specific icon mapping.

## 🚀 Quick Tips for Best Results

✅ **DO:**
- Use clear, descriptive titles
- Include specific keywords (e.g., "Tennis" not "Sport")
- Choose accurate Categories in Notion
- Be consistent with naming conventions

❌ **DON'T:**
- Use vague titles like "Community Event"
- Worry if the icon isn't perfect immediately
- Delete and recreate entries to change icons (just rename!)
