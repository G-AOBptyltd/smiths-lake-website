The village's package (Foundation · Interactive · Complete — set on the All Villages tab) is the baseline for which modules it gets. Module ON/OFF (super-admin) switches an in-package module on/off for this village — off modules are hidden from that village's admins. Public page ON/OFF controls the module's resident-facing website page only; the admin console keeps working either way.

Which role levels see which modules in this village
The matrix controls which module tiles each role level sees in this village. It cannot grant data access beyond a module's own permissions — the server checks those on every request regardless of the matrix. Unticked = hidden from that role. Super-admins always see everything.
