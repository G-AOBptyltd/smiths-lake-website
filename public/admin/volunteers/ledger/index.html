Duplicate groups

The same group exists as two content cards, so its history is split in two and a project can only claim one half. Merging rewrites every reference — working bees, app hours, volunteers, stewards and project links — onto the card you keep.

By project

Hours reach a project through the volunteer groups linked to it on the Projects page. Value = hours × that project's volunteer hour rate.

Not linked to any project
