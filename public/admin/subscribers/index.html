Ongoing sync (webhook)

In Mailchimp → Audience → Settings → Webhooks, add this URL so new subscribes/unsubscribes flow into Supabase automatically:

https://villagefirst.org.au/api/mailchimp-webhook?secret=YOUR_SECRET

Set MAILCHIMP_WEBHOOK_SECRET in Netlify to any random string and use it in place of YOUR_SECRET. Tick the subscribe / unsubscribe / profile / cleaned / email-changed events.
